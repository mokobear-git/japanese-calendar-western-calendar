# 和暦西暦・CA計算

`index.html` 1ファイルで動作するWEBアプリ（ブラウザで開くだけ。サーバー・ビルド不要）。

## 機能

1. **和暦⇄西暦**：大正・昭和・平成・令和（明治も可）を西暦 `YYYY/MM/DD` に変換。西暦（`1996/3/21`、`19960321`、`1996年3月21日`、`1996/3` など）を入れると和暦（`平成8年3月21日`、`H8.3.21`）に変換。
   - 入力例：`H8/3/21`、`平成8年3月21日`、`H8.3.21`、`H080321`、`H元.1.8`（全角も可）
   - いずれも `1996/03/21` 等に変換。カレンダーからも選択可。
   - 年月のみ（`H8年3月`、`H8/3`、`H0803`、`199603` など）も可。`1996/03` と表示。
   - 画面を開くたびに入力例の日付はランダムに変わる。
   - 改元日をまたぐ表記（例：`S64/2/1`）は換算した上で警告表示。
2. **期間**：和暦・西暦（`2026/11/7`、`20261107`、`R8年11月7日` など）の任意の組み合わせで、2つの日付の間の年月を `CA55-4` 形式で表示。
   - 併せて「55歳4か月29日」、総月数、総日数を表示。
   - 年月のみの入力を含む場合は月単位で計算（日数は表示しない）。
   - 日付Bの「日」が日付Aの「日」に達していない月は数えない。A・Bの順序は問わない。

スマホ表示では文字サイズを拡大。

## 公開（GitHub Pages）

リポジトリの Settings → Pages で Branch を選択すると `https://<user>.github.io/japanese-calendar-western-calendar/` で利用可能。
