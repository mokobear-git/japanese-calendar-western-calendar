# 和暦西暦・CA計算

`index.html` 1ファイルで動作するWEBアプリ（ブラウザで開くだけ。サーバー・ビルド不要）。

## 機能

1. **和暦→西暦**：大正・昭和・平成・令和（明治も可）を西暦 `YYYY/MM/DD` に変換。
   - 入力例：`S46/6/9`、`昭和46年6月9日`、`S46.6.9`、`S460609`、`H元.1.8`、`R8年11月7日`（全角も可）
   - いずれも `1971/06/09` 等に変換。カレンダーからも選択可。
   - 改元日をまたぐ表記（例：`S64/2/1`）は換算した上で警告表示。
2. **2つの日付の間の年月（CA）**：和暦・西暦（`2026/11/7`、`20261107`、`R8年11月7日` など）の任意の組み合わせで、間の年月を `CA55-4` 形式で表示。
   - 併せて「55歳4か月29日」、総月数、総日数を表示。
   - 日付Bの「日」が日付Aの「日」に達していない月は数えない。A・Bの順序は問わない。

スマホ表示では文字サイズを拡大。

## 公開（GitHub Pages）

リポジトリの Settings → Pages で Branch を選択すると `https://<user>.github.io/japanese-calendar-western-calendar/` で利用可能。
